# Triple image hover

Three stacked images fan out at different angles.

## How it works

CSS stacks three framed images and rotates them to 15, 7, and -5 degrees. Their entrance times are 0.5, 0.1, and 0.2 seconds. Each returns over 0.2 seconds.

## Interaction

Hover over the image stack. To toggle the fan, tap it or focus its button and press Enter or Space.

## Accessibility

Reduced motion keeps the images still. The named button has a visible focus outline; its duplicate decorative images have empty alternatives.

## Development command

Run this command from the repository root after installation.

```sh
pnpm --filter @animations/tripple-img-hover dev
```
