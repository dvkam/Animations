# Apple text reveal

Two text blocks slide into view on opposite sides of a horizontal rule.

## How it works

Overflow clips two text blocks. The top block rises for one second, with a pause halfway through. The bottom block starts after 1.4 seconds and slides down for 0.5 seconds.

## Interaction

Open the page to play the sequence. Select Restart demo to replay it.

## Accessibility

Reduced motion shows both text blocks in their final positions. The top phrase has a complete accessible label.

## Development command

Run this command from the repository root after installation.

```sh
pnpm --filter @animations/apple-animation dev
```
