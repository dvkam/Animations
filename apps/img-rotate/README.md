# Image rotation

An image grows and rotates inside a clipped frame.

## How it works

The frame clips its image. A 0.3-second transform scales the image to 1.3 and rotates it by five degrees.

## Interaction

Hover over the image. To toggle the rotated state, tap it or focus its button and press Enter or Space.

## Accessibility

Reduced motion keeps the image still. The button has a visible focus outline and the image has alternative text.

## Development command

Run this command from the repository root after installation.

```sh
pnpm --filter @animations/img-rotate dev
```
