# Text wave

Letters rise in sequence and return to the baseline.

## How it works

CSS keyframes raise each letter by 20px and return it to the baseline in a two-second cycle. Inline animation delays offset successive letters by 0.2 seconds.

## Interaction

Open the page to start the repeating effect. Use Pause autoplay to stop it at its current point.

## Accessibility

Reduced motion leaves the letters on the baseline. A separate visually hidden copy exposes the complete text to assistive technology.

## Development command

Run this command from the repository root after installation.

```sh
pnpm --filter @animations/text-wave dev
```
